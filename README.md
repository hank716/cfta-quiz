# CFTA 刷題本

CFTA（Chartered Fintech Associate）考試的互動練習網站，主要在 iPad 上使用。

**網址：** https://hank716.github.io/cfta-quiz/

## 內容

| 來源 | 題數 |
|---|---|
| CH1–CH8 章末練習題 | 199 |
| 題庫（每章 15 題） | 120 |
| 模擬考第一回、第二回 | 100 |

## 功能

- 中英對照：每題的題幹、選項和詳解都有英文版，右上角可切換「中英／EN／中」（正式考試是英文，模擬考建議用 EN）
- 練習：可以選章節、題目來源和範圍，作答後馬上看到詳解和原書小節
- 模擬考：50 題，75 分鐘倒數計時，交卷後顯示分數和各章診斷
- 錯題本：答錯的題目會自動收集，連續答對 2 次後移出
- 備份：進度存在瀏覽器裡，可以匯出和匯入 JSON

## 說明

本站題目與詳解為個人備考自編的練習題，並非官方考題，也不代表官方考試格式。
原教材 *Understanding Fintech: A Beginner's Guide to Finance in the Digital Age* 的版權屬 Global Fintech Institute，本 repo 不含原教材內容。
